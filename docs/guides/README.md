# User guides

Start with [the repository overview](../../README.md). Run guide commands from
the repository root.

| Guide | Use it for |
| --- | --- |
| [Environment](environment.md) | Install the locked base, CPU or CUDA environment |
| [Dataset](dataset.md) | Download availability, installation, verification, repair and splits |
| [Web GUI](web-gui.md) | Browse data, launch tasks, inspect logs and compare results |
| [Training and evaluation](training.md) | Explicit train/test/validate/predict commands, model choices and saved files |
| [CLI parameter reference](cli-reference.md) | Every training/evaluation argument, default, choice and task restriction |
| [Official results](official-results.md) | Curated logs/weights, reference tables and reproduction |
| [Official asset downloads](paper-assets.md) | Download, install, verify and repair weights and prediction PKLs |
| [Diagnostics](diagnostics.md) | Check the environment or model interface without external data |
| [Server acceptance](server-acceptance.md) | Test a fresh develop checkout through download, training, evaluation and merge review |

Read the paper on [ScienceDirect](https://www.sciencedirect.com/science/article/pii/S2095809926005606)
and find its [citation and BibTeX](../../README.md#citation) in the repository overview.

The code and dataset are released. These guides cover installation, downloads,
model workflows and the separately distributed checkpoint assets.
